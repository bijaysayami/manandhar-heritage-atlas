# Manandhar Heritage Atlas

Build the official website for Central Manandhar Sangh (केन्द्रीय मानन्धर संघ, ने.सं. १०७४) according to the attached specification 'Living Heritage, Connected Generations' and using the attached official logo.

Key requirements from the brief:
- Design concept: "Living Heritage, Connected Generations" — a contemporary museum- and editorial-grade digital heritage institution, not a generic NGO, corporate, or government template.
- Brand & visual identity: Respect the circular geometry, red-and-blue palette, Ranjana lipi calligraphy, and cultural symbolism of the official logo, complemented by warm Newar architectural tones (brick, terracotta, warm stone, dark wood) and subtle geometric motifs.
- Distinctive layouts: Asymmetric two-column layouts, editorial headlines with Newar heritage photography, alternating light/dark rhythm, generous whitespace, and appropriate typography with Nepali Unicode support.
- Core heritage modules:
  1. Memorable art-directed hero section with the official logo and cultural storytelling.
  2. Searchable, interactive Twa Directory for community records and twa locations.
  3. Interactive Historical Timeline and Past Presidents / committee archive.
  4. Curated Digital Library & Publications repository.
  5. Community stories, senior interviews, and cultural gallery.
- Subtle, purposeful animations: Smooth page entrance, staggered reveals, scroll-triggered section entrances, and refined micro-interactions respecting reduced motion.
